# NON-NEGOTIABLE CONSTRAINTS

• Preserve the existing design language completely.
• Do NOT redesign the application.
• Do NOT replace existing UI components unless absolutely required.
• Reuse existing components wherever possible.
• Maintain the existing theme system (light, dark, glass, motion, reduced motion).
• Preserve responsiveness across all breakpoints.
• Follow the current folder structure and architecture.
• Minimize changes to existing files.
• Prefer extending current functionality over rewriting it.
• Do not introduce unnecessary dependencies.
• Keep backward compatibility with existing projects and users.
• Maintain TypeScript strict mode.
• Ensure production build passes with zero TypeScript errors.
• Verify that no existing feature regresses.
• After implementation, provide a walkthrough of all changes, architectural decisions, and testing performed.
